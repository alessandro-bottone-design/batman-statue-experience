# Batman Statue Experience

Prototipo accademico desktop di un percorso di preordine immersivo. La missione nella Batcaverna conduce alla presentazione della statua e a un checkout dimostrativo. Usa dati fittizi per provare il checkout.

[Apri il sito pubblico](https://batman-statue-experience.vercel.app/) · [Apri il repository GitHub](https://github.com/alessandro-bottone-design/batman-statue-experience)

## Avvio locale

Usa Node.js 24, la versione configurata in GitHub Actions.

```sh
npm ci
npm run dev
```

Apri [l’anteprima locale](http://127.0.0.1:3000/). Per verificare tipi, lint, test unitari e build, esegui `npm run check`.
